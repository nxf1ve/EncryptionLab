# Лабораторная работа №3 — Магма / CFB

**Пыжов Егор · ПИбд-42 · Вариант 6**

Учебная реализация Магмы в режиме гаммирования с обратной связью по шифртексту (CFB).

## Запуск

Нужен Python 3.11 или новее с Tkinter (входит в стандартную установку Python для Windows).
Сторонние пакеты не требуются. В терминале из папки проекта выполните:

```powershell
python app.py
```

В Windows также можно использовать `py app.py`.

## Работа с программой

1. Выберите исходный файл и новое имя результата.
2. Выберите «Шифрование» или «Расшифрование».
3. Введите пароль с клавиатуры либо выберите файл с паролем.
4. Нажмите «Выполнить».

Для расшифрования нужен тот же пароль. В файле пароля учитываются все байты, включая BOM и переводы строк.
Существующие файлы не перезаписываются. Восстановленному документу или изображению задайте исходное расширение.

## Повторение опыта из отчёта

Папка `examples` сохранена в состоянии до ручной демонстрации:

- `input.bin` — исходный файл, 4099 байт.
- `password.txt` — пароль `lab3-demo`, UTF-8 без BOM и без перевода строки.
- `encrypted.magma` — заранее подготовленный пример шифрования, 4123 байта.
- `restored.bin` — заранее подготовленный пример восстановления, 4099 байт.

Файлы `test.magma` и `test_restored.bin` создаются во время опыта; изначально их нет.

1. Запустите `python app.py`.
2. Выберите исходный `examples/input.bin` и результат `examples/test.magma`.
3. Выберите «Шифрование» и «Пароль с клавиатуры», введите `lab3-demo`, нажмите «Выполнить».
4. Для расшифрования выберите исходный `examples/test.magma` и результат `examples/test_restored.bin`.
5. Выберите «Расшифрование», «Пароль из файла» и `examples/password.txt`, нажмите «Выполнить».
6. В PowerShell из папки проекта сравните хэши:

```powershell
Get-FileHash .\examples\input.bin, .\examples\test_restored.bin
```

Оба значения SHA-256 должны совпасть с результатом из отчёта:

```text
f7cf8d5c1d89392e61fee486e40244ca9b77b6acc14b4f8b729f6019e571de5b
```

Зашифрованный файл будет иметь размер 4123 байта, восстановленный — 4099 байт.
Шифртекст при повторном шифровании меняется из-за случайного IV; совпадать должны исходный и восстановленный файлы.
Для повторения опыта ещё раз выберите новые имена результата либо удалите только созданные вами `test.magma` и `test_restored.bin`.

## Файлы проекта

- `app.py` — графический интерфейс и справка.
- `magma.py` — Магма, CFB и обработка файлов.
- `test_magma.py` — автоматические проверки, показанные в отчёте.
- `examples/` — исходные материалы и подготовленные примеры для воспроизведения опыта.
- `Отчет_ЛР3_вариант_6_Пыжов.docx` — отчёт с блок-схемой, расчётом раунда и результатами проверки.

Ключ — 256 бит, блок — 64 бита. Сегмент CFB — 64 бита, регистр — 128 бит.
Ключ получают как SHA-256 от пароля. Результат содержит метку формата, случайный IV и шифртекст; размер увеличивается на 24 байта.
Учебная версия не проверяет целостность и правильность пароля. Файл читается целиком в память.
